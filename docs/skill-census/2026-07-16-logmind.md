## §4 Gaps — concrete recurring re-derivations from this release

1. **The regen-rebase merge dance**: CI auto-regens derived docs and pushes to PR branches → every local commit needs fetch+rebase, and `timeline.md` conflicts resolve by *regenerating*, never hand-merging. Re-taught to ~8 build agents by prompt this release.
2. **Byte-parity feature recipe**: additive config key defaulting to byte-identity, omitted from DefaultMap, goldens captured from *pre-change* code then re-verified. Done perfectly once (#197) — because the prompt spelled it out; otherwise tribal knowledge.
3. **Dual-review discipline**: adversarial panel + clud-bug-lens, anti-injection preamble, loop-until-green, verify-before-report. Re-specified verbatim per review; check overlap with the incoming `orchestrating-elite-agent-qa` before forging new.
4. **Worktree gotchas**: never `logmind file-structure --write` from a worktree (cwd-basename root label corrupts the tree); a worktree's `.git` is a file (hook installs must resolve the real git dir). Bit three different agents.
5. **Normative SPEC editing**: RFC-2119 house style, 4× version markers, provenance comments, §8.3 additive rules, anchor-slug verification. Re-taught per protocol-repo agent.
